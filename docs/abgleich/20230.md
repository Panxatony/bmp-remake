# Zweigbuch 20230 - Kaderbildschirm

Gelesen am 25.9.2026. 0x20230 ist der Kaderbildschirm "IHRE MANNSCHAFT". Er wird aus dem
Hauptmenü aufgerufen (Argument 0 oder 0x63) und aus der Konferenz (Argument = Zahl der Spieler
auf dem Platz, 4cb3:0664[Manager]). Die Einwechslung selbst (0x20DBC bis 0x20EF2) und das
Verlassen (0x2117E) stehen im Zweigbuch 20DBC, das Taktikbrett 0x21696 in restroutinen.md.
Remake: Web-Client `drawSquad`/`pickRow`, Server `/api/squad` (`uebernimmNummern`),
`/api/position`, `/api/einsatz`, `server/live.ts` (`applySubstitutions`).

Die Bedienung ist im Original eine andere als im Remake. Ein Linksklick auf einen Starter nimmt
ihn aus der Elf, ein Linksklick auf einen anderen Spieler setzt ihn hinein; ein Rechtsklick
außerhalb des Spiels macht einen Spieler ohne Nummer zum Reservespieler. Im Remake tauschen zwei
Zeilen ihre Rückennummern. Verglichen wird deshalb, welche Aufstellungen sich erreichen lassen.

## Befunde

| | Was | Stand |
|---|---|---|
| K1 | Verletzte und (ohne Pokalausnahme) gesperrte Spieler lassen sich im Original weder aus der Elf nehmen noch hineinsetzen. Im Remake konnte man einen verletzten oder gesperrten Spieler per Nummerntausch aufstellen | behoben: `/api/squad` weist den Tausch mit dem Text des Originals ab |
| K2 | Im Spiel kommt nur ein Spieler mit Nummer (von der Bank) aufs Feld; im Remake ließ sich auch einer ohne Nummer einwechseln | behoben; Test (wechsel.test.ts) |
| K3 | Im Spiel prüft das Original das Kontingent schon beim Auszuwechselnden nach dessen Position: nach dem Torwartwechsel lässt sich der Torwart nicht mehr herausnehmen, auch nicht für einen Feldspieler | behoben; Test (wechsel.test.ts) |
